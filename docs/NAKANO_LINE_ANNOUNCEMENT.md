## インターン生も同じLINEにいる場合、冒頭に追記する

```
※インターンの皆さんは対象外です。これまで通り公式LINEにご連絡ください。
```

中野くんはシフトのある業務委託メンバーだけに表示される（`isNakanoAvailableTo` がインターンを除外）。

## 送ったあとにやること

1. **翌日と1週間後**に管理画面 → AIの中野くん →「1日ごとの費用（直近7日）」を見る
   - キャッシュのヒット率が **95%以上なら問題なし**
   - **50%を切っていたら**原因を調べる
2. 「よくある質問」のボタンが使われているか見る。**ここはAPI代がかからない経路**なので、
   使われていないなら原因（見つけにくい／内容が合わない）を潰す価値がある
3. 答えられなかった質問がSlackに溜まるので、それを知識に足していく
